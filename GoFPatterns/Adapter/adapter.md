# Паттерн Adapter (Адаптер) в C#

## Что такое Adapter?

**Adapter (Адаптер)** — это структурный паттерн проектирования, который позволяет объектам с несовместимыми интерфейсами работать вместе.

Он выступает как «переходник» между двумя классами.

Пример из жизни:
- USB → HDMI адаптер
- Переходник для зарядки
- Конвертер форматов файлов

В программировании идея такая же:
один класс ожидает один интерфейс, а другой предоставляет несовместимый.

---

# Когда использовать Adapter?

Паттерн полезен, когда:

- есть старый код, который нельзя менять;
- используется сторонняя библиотека;
- интерфейсы несовместимы;
- нужно интегрировать разные системы.

---

# Структура паттерна

## Основные участники

### 1. Target
Интерфейс, который ожидает клиент.

### 2. Adaptee
Существующий класс с несовместимым интерфейсом.

### 3. Adapter
Класс-посредник, который преобразует вызовы.

### 4. Client
Код, использующий Target.
